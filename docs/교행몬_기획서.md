## 1. 세계관

- **무대:** 전북 14개 시군 + 완산 마을(가상) + 교육청 본청
- **교행몬:** 학교와 교육청에서 일하는 교육행정직. 트레이너와 함께 실력을 겨루며 성장
- **성장:** 레벨이 오르면 업무경감 기술 습득, 일정 레벨에서 승진(진화)
- **세계의 문제:** 업무가 쌓이면 교행몬이 「번아웃」 상태. 야근단이 이를 이용
- **주제:** 업무경감 기술로 모두가 칼퇴하는 세상

## 5. 유형 8종과 상성

- **추진력 계열(물리):** 회계, 시설, 계약, 인사
- **전문성 계열(특수):** 기획, 정보, 민원, 감사
- 효과 굉장함 2배 / 같은 유형끼리 0.5배 / 나머지 1배 (무효 없음)

| 공격 → | 효과 굉장함 | 근거 한 줄 |
|---|---|---|
| 기획 | 시설, 인사 | 계획이 공사·인력 배치를 이끎 |
| 회계 | 기획, 계약 | 예산 없으면 계획·계약도 없음 |
| 시설 | 회계, 민원 | 공사비가 예산을 흔듦, 시설 개선이 민원 해소 |
| 계약 | 시설, 정보 | 공사·전산 장비는 계약으로 움직임 |
| 인사 | 민원, 감사 | 사람을 바꾸면 응대·감사도 달라짐 |
| 민원 | 감사, 기획 | 민원 한 건이 감사와 계획을 뒤엎음 |
| 정보 | 회계, 인사 | 전산이 회계·인사 기록을 자동화 |
| 감사 | 계약, 정보 | 계약·전산 보안이 단골 점검 대상 |

| 방어 유형 | 약점 |
|---|---|
| 기획 | 회계, 민원 |
| 회계 | 시설, 정보 |
| 시설 | 기획, 계약 |
| 계약 | 회계, 감사 |
| 인사 | 기획, 정보 |
| 민원 | 시설, 인사 |
| 정보 | 계약, 감사 |
| 감사 | 인사, 민원 |

- 유형마다 강점 2, 약점 2로 균형
- 스타터 삼각형: 기획 > 시설 > 회계 > 기획

## 10. 전투 규칙 (원작 구조)

- 1대1 턴제, 파티 최대 6, 기술 최대 4개, 레벨 최대 100
- 능력치 5종: 체력 / 추진력 / 내공 / 전문성 / 처리속도
- 행동 순서: 처리속도 순 (선제 기술 우선)
- 데미지 = ((2×Lv÷5+2) × 위력 × 공격÷방어 ÷ 50 + 2) × 같은 유형 1.5 × 상성 × 급소 2 × 난수(0.85~1.0)
- 급소율: 처리속도 기반
- 능력 단계 ±6
- 영입: 상대 체력이 낮고 상태이상일수록 발령장 성공률↑. 트레이너 교행몬은 영입 불가
- 경험치: 쓰러뜨린 교행몬 레벨·종류 기반, 참여한 교행몬끼리 나눔
- 인사교류 받은 교행몬: 경험치 1.5배, 배지 부족하면 명령 불복종
