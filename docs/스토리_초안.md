# 교행몬 — 스토리 초안 (2026-10-21 갱신)

## 핵심 설정 (호용님 확정)
- 몬스터 = 교육행정직 「교행몬」
- 레벨업마다 기술 습득, 기술 = 업무경감 기술
- 체육관 14곳 = 전북 14개 시군 교육지원청
- 주인공 = 교행몬 마스터를 꿈꾸는 교행몬 트레이너 (직종 설정 없음)
- 스타터 3종 = 기획형·회계형·시설형

## 유형 8종 (확정)
- 기획, 회계, 시설, 계약, 인사, 민원, 정보, 감사
- 합친 것: 급여·노무·복지 → 인사 / 재산 → 시설 / 데이터 → 정보 / 법무 → 감사
- 의회는 유형에서 빼고 최종 관문 전용
- 체육관 14곳은 유형 중복 허용
- 스타터 상성: 기획 > 시설 > 회계 > 기획

## 제안 (미확정)
- 진화 = 승진 (9급 → 7급 → 6급 실장 → 5급 사무관)
- 기술 예시: Lv5 피벗 정리, Lv12 서식 일괄 적용, Lv20 스캔 자동 이름변경, Lv30 AI 요약
- 영입 도구 = 몬스터볼 대신 「발령장」
- 야생 조우 = 업무 난제 (공문 폭탄, 중복 제출, 수작업 엑셀)
- 악당 = 「야근단」, 최종 관문 = 예산 편성·행정사무감사·국정감사·결산

## 지킬 것
- 원작 느낌(4색 도트, 타일맵, 하단 대화창, 턴제 메뉴)은 장르 관례로 사용
- 원작 이름·몬스터·그림·로고·효과음은 사용 금지, 전부 자체 창작
- 기술·퀴즈에 실제 절차를 넣을 경우 출처 확인된 내용만
